# Fora dos Tribunais

Site do projeto **Fora dos Tribunais**: soluções consensuais de conflitos (mediação, conciliação e negociação) antes do litígio. Iniciativa de estudantes do Ibmec Brasília.

Site estático (HTML, CSS e JS em um único arquivo), sem build.

## Publicar na Vercel
1. Importe este repositório em vercel.com/new
2. Framework Preset: **Other** (deixe build e output em branco)
3. Deploy

## Aviso
Projeto de estudantes. Não presta serviços de advocacia nem consultoria jurídica.
